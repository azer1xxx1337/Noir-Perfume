# NOIR Parfums

### 🔗 Live: **[azer1xxx1337.github.io/Noir-Perfume](https://azer1xxx1337.github.io/Noir-Perfume/)**

Luxury perfume store concept: a real-time 3D flacon on a black marble pedestal over a liquid-gold floor, all lighting and backgrounds rendered by hand-written WebGL shaders (no stock photos).

- Catalogue with filters, product pages, cart
- Scent finder by mood
- Tap the bottle: the cap opens and it sprays
- Single self-contained `index.html` (Three.js from CDN)
